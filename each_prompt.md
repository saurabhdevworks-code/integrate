### Revert Mechanism Guidelines:
1. **User Command**: Jab bhi aap kahein, e.g. *"Revert PR-013"* ya *"PR-008 wapas pehle jaisa kar do"*.
2. **Action**: Main `each_prompt.md` se us ID ke exact files aur changes identify karke rollback execute kar dunga aur `each_prompt.md` me ek new revert entry add kar dunga.
